# Fiesta en Cadena

crear una pagina web, canchera, moderna, funcional, que sirva de invitacion para cumpleaños. Cada link es dinamico, y se genera uno general, el invitado al registrarse, pone su nombre completo y email para recibir el QR, nada mas. una vez completado y aceptar la invitacion se genera un link de invitacion para sus amigos, le ponemo un copy que diga que puede invitar a a 2 o 3 amigos, y ese link que se generra es dinamico exclusivamente de el, para que sepamos de parte de quien viene el proximo invitado.

el diseño tiene que ser fresco, moderno, dinamico con moviemito y apto android y ios.
